# Project 20: Optimal DG Placement — IEEE 38-Bus Network

Domain: Power Systems / Optimization / MATLAB

Files:
- neworiginaldg.m — Main GA optimization for DG placement
- versionwithdgs.m — Version with fixed/optimal DG toggle
- input.m — IEEE 38-bus network data (bus and line data)

Usage: Set use_fixed_dg = true/false at top of script.
If true, set fixed_dg_count to desired number.

Requirements: MATLAB R2024a (use MATLAB Online for 
older versions — compatibility issue with 2022a confirmed)
