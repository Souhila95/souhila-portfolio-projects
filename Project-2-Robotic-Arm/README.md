# Souhila Meziane — Research Portfolio Projects

## Project 2: 3-DOF Robotic Arm — Jacobian Matrix & Simulink Servo Control

**Domain:** Robotics / Control Systems / Kinematics

What's in this repo:
- `untitledservo2.slx` — Simulink model simulating 3 servo motors with PWM control and degree plotting (0° to 180°)

About the project:
Full kinematic analysis of a real 3-joint robotic arm (2 rotoid + 1 prismatic joints, d1=215mm, d2=163.56mm). Includes Jacobian matrix derivation, Direct and Inverse Geometric Models, and PWM servo simulation in Simulink.

Requirements: MATLAB/Simulink R2016a or later
