# Project 5: ECG Signal Processing & R-Wave Detection

Domain: Biomedical Engineering / Signal Processing

## What's in this folder
- `finalcode.m` — Final ECG R-wave detection with restructured variable names and comments
- `kok.m` — Filter-injected version matching target waveform output
- and additional plotting files

## About the project
Fixed and extended a broken ECG signal processing program based on 
MathWorks wavelet R-wave detection. Developed signal filtering, 
axis labeling, line-by-line documentation, and remote debugging.

Dataset used: MIT-BIH format ECG signal (mit200.mat)

**Requirements:** MATLAB R2016a or later
