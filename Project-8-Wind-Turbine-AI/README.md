# Project 8: AI-Based Wind Turbine Failure Prediction

Domain: Renewable Energy / Predictive Maintenance / Neural Networks

Files:
- Turbinlunch.m — Main launch script (open with mine2.mat to simulate)
- mysimmodel.slx — Simulink dynamic wind turbine model
- mine2.mat — Dataset and trained neural network model

Usage: Open Turbinlunch.m + mine2.mat in MATLAB, run simulation.
Simulink model opens automatically.

Requirements: MATLAB R2016a or later with Neural Network Toolbox

Contributed to Scopus publication:
Dong Hwa Kim, "Failure Prediction of Wind Turbine using Neural
Network and Operation Signal", IJRTE Vol.10, No.4, Dec. 2021.
