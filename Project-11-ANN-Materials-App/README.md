# Project 11: ANN Melting Temperature Prediction + Standalone App

Domain: Materials Science / Neural Networks / MATLAB App Development

Files:
- MycodeANN.m — Main ANN training code with adjustable parameters
- predictioncode.m — Prediction using saved net model
- testmodel.m — Model testing script
- Appcode.m — Standalone app generation code (use with MATLAB Compiler)

Usage: Open with corresponding .mat model file, run simulation.
For app generation: rename chosen model to "mynet.mat", 
open Appcode.m in MATLAB Compiler, click Package.

Requirements: MATLAB R2021a, Neural Network Toolbox,
MATLAB Compiler (for app generation)
