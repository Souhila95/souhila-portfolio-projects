3-DOF Robotic Arm — Simulink Servo Control

Simulink model simulating 3 servo motors (PWM control) 
for a real 3-joint robotic arm (2 rotoid + 1 prismatic).

- untitledservo2.slx — Main simulation with PWM signal 
  and degree plotting (0° to 180°)

Requirements: MATLAB/Simulink R2016a or later

Part of a robotics kinematics project including full 
Jacobian matrix derivation and geometric modeling.
