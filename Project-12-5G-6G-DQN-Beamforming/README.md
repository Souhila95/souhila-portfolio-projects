# Project 12: 5G/6G Beamforming Optimization with Deep RL

Domain: Wireless Communications / Reinforcement Learning / MATLAB

About: DQN-based beam selection optimization for 5G/B5G/6G 
systems. Custom MATLAB environment simulating 10-user mobile 
scenarios with base station beamforming. Agent learns optimal 
beam selection policy to maximize RSRP signal quality.

Key specs:
- Frequency: 300 THz (6G prototype range)
- RL method: Deep Q-Network (DQN)
- Metric: Average RSRP, Energy Efficiency, Spectral Efficiency

Requirements: MATLAB R2022a, Reinforcement Learning Toolbox,
5G Toolbox
